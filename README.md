# 📊 Data Visualization: Gráficos de Composição e Relacionamento

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/VictorGMSS/Alura_Visualizacao_de_dados_composicao_e_relacionamento/blob/main/Projeto_Inicial_Data_Visualization__gr%C3%A1ficos_de_composi%C3%A7%C3%A3o_e_relacionamento.ipynb)

Projeto prático desenvolvido durante o curso na **"Alura"**. O objetivo deste repositório é aplicar técnicas de visualização de dados voltadas para **composição**, **correlação** e **relacionamento entre variáveis**, usando Python, com foco na escolha do gráfico ideal para cada cenário, na personalização visual e nas boas práticas de comunicação de dados.

---

## 🎯 Objetivos do Projeto

* **Gráficos de Composição:** Criar visualizações que mostrem como as partes se distribuem em um todo, como gráficos de pizza e barras empilhadas.
* **Gráficos de Relacionamento:** Explorar a relação entre variáveis com gráficos de dispersão, mapas de calor, pairplots e gráficos de bolhas.
* **Escolha do Gráfico Ideal:** Identificar qual tipo de gráfico é mais adequado para cada cenário e tipo de informação.
* **Personalização Visual:** Aplicar paletas de cores, temas, anotações, configuração de eixos, legendas, títulos e ajustes de layout.
* **Boas Práticas:** Destacar informações relevantes e tornar os gráficos claros e informativos.
* **Visualizações Interativas:** Construir gráficos interativos para explorar os dados.
